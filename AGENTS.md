# VR-переполох

## Концепция и рамки

Оригинальная одностраничная 2D-игра в стилистике смешной VR-лаборатории для компьютера. Игрок проходит три короткие головоломки мышью или клавиатурой. Внешние API, аккаунты и сетевые зависимости не нужны.

## Нерушимые правила

- Общий лимит одной попытки — 60 секунд на все три уровня.
- Состояния: `idle`, `running`, `paused`, `won`, `lost`.
- Победа наступает только после трёх головоломок, поражение — при нулевом времени.
- Пауза замораживает таймер и весь игровой ввод; перезапуск полностью очищает прогресс.
- Уровни: эмоции аватаров, трёхзначный код, панель «крест» 3×3.

## Управление и доступность

- Любое действие доступно мышью через видимые кнопки.
- Клавиатура: `1`–`3` и `Enter`; цифры, `Backspace`, `Enter`; стрелки и `Space`/`Enter`.
- `P` управляет паузой; `R` перезапускает после финала.
- Используются `KeyboardEvent.code`, заметный фокус и `prefers-reduced-motion`.

## Технология и структура

Статические HTML/CSS/JavaScript без зависимостей. `src/game.js` — авторитетная модель, `src/main.js` — DOM-рендер и ввод, `tests/` — тесты Node, `scripts/` — сборка и сервер. Результат сборки — `dist/`.

## Проверка

Выполнить `npm test` и `npm run build`. В браузере проверить старт, оба типа управления, паузу, победу, поражение, перезапуск, размеры desktop/mobile, отсутствие горизонтальной прокрутки и ошибок консоли.

## Git и публикация

Работать в ветках `codex/*`. Не коммитить, не публиковать, не создавать удалённый репозиторий или PR без явного согласия пользователя. Для будущего PR сначала проверить корень репозитория, ветки, diff, сборку и реальные ссылки превью.
