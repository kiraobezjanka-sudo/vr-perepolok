# VR-переполох

Смешная браузерная VR-головоломка: за 60 секунд почините аватаров, откройте гравитационный холодильник и стабилизируйте котопортал.

## Играть

[Открыть временное превью Pull Request №1](https://kiraobezjanka-sudo.github.io/vr-perepolok/pr-preview/pr-1/)

Ссылка действует, пока Pull Request открыт. После слияния её заменит постоянный production-адрес.

## Как играть

- Пройдите все три уровня до окончания общего таймера.
- Мышь работает со всеми элементами игры.
- Уровень 1: клавиши `1`–`3`, затем `Enter`.
- Уровень 2: цифры, `Backspace` и `Enter`.
- Уровень 3: стрелки и `Space`/`Enter`.
- `P` — пауза или продолжение, `R` — новая попытка после финала.

## Запуск и проверка

```bash
npm start
npm test
npm run build
```

Откройте `http://127.0.0.1:4173`. Игра не требует установки зависимостей или подключения к интернету.

## Структура

- `src/game.js` — правила и состояние игры;
- `src/main.js` — интерфейс, управление и звук;
- `styles.css` — адаптивный визуальный стиль;
- `tests/` — проверки игровых правил;
- `scripts/` — локальный сервер и статическая сборка.
